# Phase 3: Generation

Goal: at least three really different ways to act on the idea, so the choice in phase 4 is a
real choice.

## Make them different

Vary one of these per variant, not just the size:

- **Who it is for** (a different user or buyer).
- **Mechanism** (how it solves the problem: tool, service, content, community, automation).
- **Business model or goal** (free and open, paid, a portfolio piece, a learning project).
- **Scope of the bet** (the smallest version that tests the thesis vs the full product).

Use the briefing: a variant that a competitor already does well needs a reason to exist;
an underserved channel found in the sweep is a variant. Cite claims as [C#].

Include one variant the user did not ask for, if the evidence points to it. Include "do not
build; use or extend X" when the sweep found a good existing option.

## Record

`idea_phase(action=record, kind=variants, content=[...])`, at least 3 items:

```json
{"name": "...", "summary": "...", "who_for": "...", "why_it_could_win": "...",
 "biggest_risk": "...", "evidence": ["C3", "C7"]}
```

Present them briefly, then `idea_phase(action=advance)`.
